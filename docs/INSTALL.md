# Installation

## Prerequisite

A Fedora or OpenSUSE Tumbleweed installation (preferably with Gnome).

Ubuntu is partially supported (doesn't include the Hyprland desktop).

## Setup

The script takes care of everything:

```sh
./install.sh
```

Then restart and select Hyprland on the log-in screen.

Note: The software is provided "as is", without warranty of any kind. Make sure you understand the Ansible roles and provided dotfiles before proceeding.
